🔧 How to Optimize Your Images:

Option 1: Online Tools (Free)

  • TinyPNG: [tinypng.com](https://tinypng.com) - Drag & drop, get optimized versions
  • Squoosh: [squoosh.app](https://squoosh.app) - Google's tool, very powerful
  • Compressor.io: [compressor.io](https://compressor.io) - Easy to use

Option 2: Photoshop/Image Editing Software

  • Save for Web (File > Export > Save for Web)
  • Choose JPEG quality 80-85
  • Resize to appropriate dimensions

Option 3: Command Line (Advanced)

  • Use ImageMagick or similar tools
  • Batch process multiple images

💡 Pro Tips:

  • Use JPEG for photos, PNG for graphics with transparency
  • Always test on mobile devices - slower connections show loading issues first
  • Consider using WebP format for even better compression (with JPEG fallback)
  • Implement lazy loading for portfolio pages
